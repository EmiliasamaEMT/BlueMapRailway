### 编辑规则纯计算迁移

新增 `core/src/main/java/io/github/emiliasamaemt/bluemaprailway/edit/RailEditProcessor.java`，提供无状态入口：

```java
RailScanResult apply(
    RailScanResult result,
    List<RailEditMask> masks,
    List<RailEditHideRule> hiddenLines
)
```

处理器只接收 core 数据和规则，不访问世界、配置文件、日志或线程。Paper `RailEditRegistry` 与 Fabric `FabricEditRegistry` 保留各自的 YAML 加载、保存、删除和查询方法，`apply` 改为委托给该处理器；重复的隐藏、box clipping、片段拆分代码已移除。

迁移保持原有语义：隐藏先于裁切；规则和片段按原顺序处理；`nodes`、扫描/缓存计数和 `hiddenLineCount` 原样传递；component 只按输出片段存在性过滤；`withPoints` 保留线路 route 元数据；空规则、空线路和 `null` 结果仍原样返回；`EPSILON=1e-6`、闭区间和 `max + 1.0` 边界未改变。

### 固定输入测试

新增 `core/src/test/java` 下三组测试，共 8 个测试方法：

| 测试类 | 覆盖内容 |

| `scan/RailGraphBuilderTest` | 三节点平直线、T 型岔点；component/line 数量、端点方向和邻接关系 |

这些夹具只使用 `core` 数据对象和纯计算类，不创建 Paper/Fabric 世界对象，也没有写 YAML 或文件副作用。测试断言保留业务不变量：岔点不被错误压成一条线、不同样式不合并、编辑规则可区分启用状态和目标范围。
