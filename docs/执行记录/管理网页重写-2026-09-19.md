# 管理网页重写执行记录

日期：2026-09-19。起点提交：8d6f306。发布版本：0.2.1。

## 范围与实现

用户优先要求外观、功能与性能。重写完整样式系统和空间索引，改造 HTML 工作台结构、地图绘制调度、请求竞态处理与列表分页；复用稳定 HTTP 协议和既有 CRUD 业务函数。没有宣称每个旧函数都已重写。

- 浅色绿色工作台，桌面/平板侧栏、手机可收起面板，地图缩放按钮。
- 视口候选绘制、按帧合并、SVG 交互覆盖层节点复用、自适应网格、DPR 最高 2。
- 缓存 bounds，索引写入和查询均限制格子枚举；大对象走候选回退。
- 隐藏/其他世界线路先过滤再命中；保留源数据顺序和全局样式组顺序。
- 线路列表每页 60 项；坐标必填；重复保存抑制；草稿刷新保护；诊断耗时展示。
- 过期 state 响应忽略，轮询防重入、隐藏页面暂停，页面关闭取消渲染和定时器；底图加载防旧回调覆盖。

## 决策

按项目要求做有界架构咨询：保留 API/store/public map 方法契约，渲染内部改为失效调度；setData 同步重建索引保证点击不读取旧几何。大查询/大对象用缓存 bounds 回退。SVG 导出仍默认关闭；网页内交互 SVG 不属于暂停模块。

## 验证

- Node 单元测试：21 项通过，含巨大对角线、全图查询、候选顺序、显隐/世界过滤、帧合并、视口外剔除、底图竞态。
- Playwright：单 worker，22 项通过，覆盖桌面和 768px，额外在 390px 验证手机面板；线路/站点/裁切保存、必填、草稿保护、刷新重试、分页。
- 十万条短线索引本机样本：构建 32 ms，1 万次最近线查询 159 ms。不是整体页面性能，也不是服务器 MSPT；无同环境前后对照，不计算提升百分比。
- 截图：build/admin-web-0.2.1-desktop.png、admin-web-0.2.1-narrow.png、admin-web-0.2.1-mobile.png、admin-web-0.2.1-admin-desktop.png。均为模拟数据。
- 第一轮样式回归发现搜索栏遮挡编辑按钮，修复显示优先级和定位后，最终 22 场景全部退出 0。

## 剩余边界

尚未完成真实大地图浏览器 FPS/堆内存测量、站点/规则列表虚拟化、触屏双指缩放、扫描中保存的真实服测试。大对象很多时索引仍需线性 bounds 遍历；全图视口仍会绘制所有可见线；选中大量 component 时 SVG 选择节点仍可能较多。

本轮只启动 Playwright 管理的 mock server，未启动 Minecraft 测试服。mock server 随测试 teardown 退出。

双端构建通过：Java 25，离线、单 worker、no-daemon，JVM `-Xms128m -Xmx512m -XX:MaxMetaspaceSize=384m`。首次沙箱构建遇到 Loom 临时映射文件锁查询失败，提升访问权限后通过；未删除缓存。两个 `0.2.1` JAR 内的 6 个修改过的网页资源逐字节与源码一致，`plugin.yml` 与 `fabric.mod.json` 版本均为 `0.2.1`。

产物：`paper/build/libs/BlueMapRailway-0.2.1.jar`、`fabric/build/libs/BlueMapRailway-fabric-0.2.1.jar`。本轮未部署真实服；Release 将由 `v0.2.1` tag 的 GitHub Actions 创建。

最终清理复核：25565/8100/8765/8766/18765/25575 无监听，Java/Gradle 进程无残留。
