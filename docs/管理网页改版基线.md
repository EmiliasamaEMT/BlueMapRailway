# 管理网页改版基线

记录日期：2026-07-12

本文件用于固定管理网页重构前的行为、接口和回归范围。重构阶段首先保证功能等价，再逐步替换布局与渲染实现。

## 基线构建

```powershell
.\gradlew.bat :paper:build :fabric:build "-PpluginVersion=0.1.22-baseline"
```

构建结果：Paper 与 Fabric 均构建成功。

## 当前功能

### 浏览与地图

- 默认进入只读浏览模式。
- 显示自定义底图或 JAR 内置底图。
- SVG 显示铁路、站点范围、裁切范围和框选草稿。
- 支持滚轮缩放、拖动平移、适应全部对象和实时 X/Z 坐标。
- 支持底图透明度与白色遮罩调节。
- 点击铁路、站点或裁切区域查看对象信息。

### 管理登录

- Token 保存在浏览器 `localStorage`。
- `/api/auth-check` 验证 Token。
- 浏览模式只能读取公开状态；管理模式额外获得裁切规则与隐藏规则。
- 所有修改接口必须通过查询参数或 `X-BlueMapRailway-Token` 请求头认证。

### 线路

- 点选 component，重复点击取消选择。
- 框选多个 component，Shift 追加选择。
- 创建或修改线路的 ID、名称、颜色、线宽、自动延续和 component 绑定。
- 点击已有线路载入编辑、定位、隐藏或删除。
- 保存空 component 列表可清空线路绑定。
- 可以隐藏选中未分类 component，或隐藏整条 route。

### 站点

- 框选站点 X/Z 范围并填写 Y 范围。
- 创建、修改、定位和删除站点。
- 已保存站点始终显示范围框。

### 裁切与隐藏

- 框选裁切规则范围并填写 Y 范围。
- 创建、修改、启停、定位和删除裁切规则。
- 裁切范围默认仅在列表聚焦后显示。
- 查看和删除隐藏线路规则。

### 扫描

- 管理员可请求全量重扫。
- 保存线路、站点、裁切或隐藏规则后重新请求状态，并由后端排队扫描。

## HTTP API 基线

| 方法 | 路径 | 认证 | 用途 |
| --- | --- | --- | --- |
| GET | `/`、`/index.html` | 否 | 页面 |
| GET | `/style.css`、`/app.js` | 否 | 静态资源 |
| GET | `/background.png` | 否 | 管理底图 |
| GET | `/api/state` | 可选 | 浏览状态；认证后包含管理数据 |
| GET | `/api/auth-check` | 可选 | 返回 Token 是否具有管理权限 |
| POST | `/api/route` | 是 | 新建或更新线路 |
| POST | `/api/route/delete` | 是 | 删除线路 |
| POST | `/api/station` | 是 | 新建或更新站点 |
| POST | `/api/station/delete` | 是 | 删除站点 |
| POST | `/api/mask` | 是 | 新建或更新裁切规则 |
| POST | `/api/mask/delete` | 是 | 删除裁切规则 |
| POST | `/api/hide-line` | 是 | 新建或更新隐藏规则 |
| POST | `/api/hide-line/delete` | 是 | 删除隐藏规则 |
| POST | `/api/rescan` | 是 | 请求全量重扫 |

`/api/state` 的稳定字段为：`ok`、`admin`、`background`、`bounds`、`routes`、`stations`、`masks`、`hiddenLines`、`components`、`lines`。重构可以追加字段，不应删除或改变现有字段含义。

## 请求体基线

- 线路：`id`、`name`、`color`、`lineWidth`、`autoMatch`、`componentIds`。
- 铁路折线：`componentId`、`world`、`type`、`powered`、`routeId`、`routeName`、`color`、`lineWidth`、`points`。
- 站点：`id`、`name`、`world`、`minX/minY/minZ`、`maxX/maxY/maxZ`。
- 裁切：站点范围字段，加 `enabled`。
- 隐藏：`id`（可选）、`name`、`enabled`、`routeIds`、`componentIds`。
- 删除：`id`。

## 回归清单

- [ ] 未输入 Token 时进入浏览模式，管理数据和管理控件不可见。
- [ ] 正确 Token 可进入管理模式，错误 Token 不改变模式。
- [ ] 页面刷新后 Token 和本地视图设置仍保留。
- [ ] 平移、缩放、坐标显示和适应范围正确。
- [ ] 底图、网格、线路、站点、裁切和选择层顺序正确。
- [ ] 点选线路可选择和取消；Shift/框选可追加多个 component。
- [ ] 线路创建、修改、清空绑定、隐藏和删除请求保持兼容。
- [ ] 站点框选、修改范围、定位和删除保持兼容。
- [ ] 裁切创建、启停、聚焦显示、修改和删除保持兼容。
- [ ] 隐藏规则查看和删除保持兼容。
- [ ] 删除和重扫需要确认。
- [ ] 保存中、成功和失败均有明确反馈。
- [ ] 只改变选择状态时不重新加载底图。
- [ ] Paper 与 Fabric 使用同一份前端资源和 API 字段。
- [ ] 桌面、窄屏和大量线路数据下不发生控件重叠。
